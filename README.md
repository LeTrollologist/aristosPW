# Aristos Property Works

Welcome to the **Aristos Property Works** repository. This is a highly professional, modern, and reactive single-page website built for high-end residential and commercial property maintenance services. The platform emphasizes technical troubleshooting, system diagnostics, and cosmetic fixture updates.

## 🚀 Features
- **Premium Aesthetics**: Features glassmorphism (frosted glass), custom mesh gradients, and magnetic button interactions.
- **Scroll Reactivity**: Smooth, staggered scroll animations powered by native `IntersectionObserver`.
- **Light & Dark Mode**: Seamlessly transition between bright professional themes and deep, sleek dark themes based on user preference or system settings.
- **Interactive Before/After Slider**: A drag-to-reveal slider to visually demonstrate property updates and hardware swaps.
- **Local SEO Optimized**: Invisible JSON-LD schema markup establishes clear service boundaries (Youngstown, Boardman, Warren, etc.) without relying solely on on-page text.
- **Mobile First**: Built with CSS flexbox and responsive media queries to ensure the site looks stunning on any device.

## 🛠️ Tech Stack
This project is built using native web technologies for maximum performance and minimum dependencies:
- **HTML5**: Semantic and accessible structure.
- **Vanilla CSS3**: Uses CSS variables for theming, advanced selectors, animations, and transitions. No preprocessors or CSS frameworks required.
- **Vanilla JavaScript**: Lightweight DOM manipulation for theme toggling, interactive sliders, and scroll animations.

## 🖥️ Local Development
To view the site locally, simply clone the repository and open `index.html` in your favorite web browser.
```bash
git clone https://github.com/LeTrollologist/aristosPW.git
cd aristosPW
```

No build steps, bundlers, or package managers are required.
